# Thanksgiving run of show

A mobile web app for the Thanksgiving kitchen schedule: a live oven / slow cooker / stovetop strip, a checklist of steps, and filters for HL and RH.

## On iPhone

1. Open the GitHub Pages link in Safari.
2. Tap **Share → Add to Home Screen**.
3. Launch it from the home screen. It opens full screen, works offline, and keeps the screen awake while open.

On Thanksgiving (Nov 26, 2026) it follows the real clock. On other days, drag the slider to preview any time. Checkmarks are saved on each phone separately.

## Files

- `index.html`: the whole app
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-*.png`: home-screen install
- `sw.js`: offline caching
